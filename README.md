# PositivoDataSync
 Importador de dados para planilha excel, com intuito de automatizar parte do processo contábel de um escritório.
 
 O aplicativo lê os PDF buscando palavras chaves, onde em um segundo momento, ele localiza a aba da planilha por data, e escreve cada informação por coluna e número.
 
 Também conta com layout e tratamento de erros, executando o backup da planilha com uma cópia a cada uso.
